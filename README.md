# PLUGIFY Store

Premium yellow-and-black ecommerce storefront for PLUGIFY.

This branch is deployment-ready for Render. The complete storefront source is packaged in `plugify-store-deploy.zip`, while `render.yaml` builds and publishes it automatically.

## Render
Create a new Blueprint from this repository and select the `plugify-store` branch. Render will use `render.yaml` to build the storefront.

Storefront includes product catalogue, search/filtering, product pages, cart, checkout prototype, support pages, responsive mobile navigation and PLUGIFY branding.
